# エンカレ夢中万博 サイト

来場者向けの案内ページ。パンフレットの QR からここへ来る想定（10/27 実行委員連絡「詳しい内容はすべてWebサイトに掲載」）。

- `index.html` … 本文。文章はここを直接書き換える
- `style.css` … 見た目（色はポスターに合わせている）
- `img/poster.jpg` … ポスター（1200px に縮小）
- 出し物の絞り込みは各 `<article class="item">` の `data-kind`（eat／play／see）で決まる
- 版を上げたら、`index.html` の下の帯（`v0.1.0`・更新日・更新履歴）と `CHANGELOG.md` を両方直す

公開先：https://yuyami-meguru.github.io/muchu-expo/（GitHub Pages、main を push すると数十秒で反映）
パンフ用QR：`docs/print/qr.svg`（印刷向け）・`docs/print/qr.png`

確認：`~/Desktop/.claude/launch.json` の `muchu-expo`（ポート 8810）

## 「準備中」になっている所（決まったら埋める）
- エンカレ茶屋・地域部門の場所
- 唐揚げの価格
- 地域部門の企画内容（9/2 のプレゼンで決まった内容）
- 個人発表の時間、ラジオ生放送の時刻
- 駐車場の有無
- バス・電車での行き方
- 住所の番地（検索では「安佐南区伴北六丁目」まで。学校に確認）

## 載せる前に確かめたいこと
- 入場料・支払い方法（現金のみ等）
- 写真撮影のルール
- 雨の日の扱い（屋外テントの出し物）
- 問い合わせ先（学校の電話番号を載せてよいか）
- 生徒・先生の名前は載せていない（未成年の情報のため）
