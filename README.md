# エンカレ夢中万博 サイト

2026年11月28日（土）の「エンカレ夢中万博」の公式サイト。**サイト制作：AVERIX**（主催は広島工業大学高等学校 通信制課程 エンカレッジコース・エンカレ夢中万博 実行委員会）。**https://encare-dream-expo2026.encourage-school.averix.jp**（Vercel。muchu-expo.vercel.app でも開ける）。
AVERIX ハブと同じ作り（Next.js ＋ Vercel）で、
**お客さん側**と**従業員側（お店の人・実行委員）**に分かれている。

| 区画 | URL | だれが | できること |
|---|---|---|---|
| お客さん側 | `/` `/shops` `/shops/[id]` `/schedule` `/map` `/info` `/survey` `/radio` `/award` | だれでも | いまの売り切れ・お知らせ（自動更新：開催中 15 秒・当日の朝 30 秒・開催前 2 分・終了後 1 分ごと）、全体の帯（雨・急ぎ）、お店のメニュー・値段・当日の流れ・お店の思い・小さな見取り図・［このページを送る］、タイムテーブル（行ごとの場所・「あと N 分」）、地図（外と建物の中のフロア＝知育館 2〜4 階の見取り図、お店の場所・トイレ・受付など、階ごとの案内）、困ったときは・次の送迎バス。開催前・当日・終了後で出し方が変わる。非表示のお店は、実行委員とそのお店の人だけ「下見」の帯つきで見られる |
| お店の人 | `/join`（お店の QR）→ `/staff` | 各お店 | 自分のお店の売り切れ・営業中など・お店からのお知らせ、紹介（ひとこと・説明・思い・当日の流れ・メニューと値段）、お客さんに見せる準備（そろっているか・まだの欄へ飛ぶ。開催前は上、当日はたたんで下）、実行委員からの連絡と［見ました］、押した結果の［元に戻す］、返事が来ないときは保存できたかを読み直して確かめる、ほかの人が直した欄は上書きしない（409 で知らせる） |
| 実行委員・先生 | `/staff/login`（合言葉）→ `/staff` | 実行委員 | いまの様子（運営の状態の 1 行・お店の人への連絡の既読・ログインの期限の帯）、全部のお店の編集（変えた欄だけ送る）・一覧で営業／売り切れ／隠す・名前で探す・しぼり込み・準備の進み具合（準備ができたお店 5／9・まだのお店だけ）、部門、地図のピン（お店の場所をまとめて決める）、全体のお知らせ・全体の帯・お店の人への連絡、お店の人に配る QR、会場に貼るポスター・フロアごとの案内・受付用の索引・控えの紙（刷る前の確かめつき）、当日の道具（一斉に営業中・終了・まとめて戻す・控え・表示の時期・チェックリスト）、変更の記録・当日の動き、アンケートの集計、校内ラジオ、夢中アワード |

ほかのお店を書き換えようとするとサーバーで断る（`npm run check:auth`・`check:tools`・`check:survey`・`check:radio`・`check:award`・`check:live`・`check:map`）。使い方はサイトの中の `/staff/help`。

保存先（Upstash）は無料枠（月 50 万回）の中で当日を乗り切れるよう、同時の読みの相乗り・数秒の使い回し・時期ごとの更新の間隔・連打をメモリで止める作りにしてある（11 月の見積もり 約 24 万回）。

当日よく変わる物（売り切れ・営業の状態・お店からのお知らせ）は、お店の中身とは別に 1 つずつ保存する（Redis の `muchu:live`）。同時に押しても、ほかの人の変更が消えない。運営の道具（お店の人への連絡・全体の帯・表示の時期・チェックリスト）は `src/lib/ops.ts`。お客さんに見せる準備の決め方（要るもの・あるとよいもの）は `src/lib/readiness.ts`。

## フォルダ
- `src/app/(public)/` お客さん側の画面　`src/app/staff/` `src/app/join/` 従業員側の画面　`src/app/api/` 保存の窓口
- `src/components/ui` `src/components/shell` … AVERIX ハブから持ってきた部品と枠（色だけ `src/app/globals.css` で夢中万博に）
- `src/lib/store.ts` 保存先（本番は Upstash Redis、手元は `.data/dev.json`）　`src/lib/auth.ts` ログイン　`src/lib/seed.ts` はじめのデータ
- `src/lib/ops.ts`・`ops-server.ts` 当日の運営の道具（開催の時刻・表示の時期・全体の帯・お店の人への連絡・チェックリスト）　`src/app/staff/_lib/use-staff-live.ts` 従業員側の 15 秒ごとの読み直し
- `vercel.json` サーバーの場所（東京 hnd1。Upstash と同じ場所にして往復を速く）
- `src/lib/venue.ts` 会場の名前・住所・位置（Apple マップ／Google マップのボタンと埋め込みの地図）。**正確な位置が分かったら point に入れる**
- `src/components/map/school-map.tsx` 校内マップ。外の絵は `campus-shapes.ts`（OpenStreetMap の建物と道の形）、フロアの絵は `floor-plan.tsx`。建物の名前はピンで付ける
- `src/lib/floor-plans.ts` 知育館 2〜4 階の見取り図（実行委員の「会場配置図エディタ」の建物の形だけ。物品と人の名前は入れない）と、はじめに入れる部屋の四角
- `public/sw.js` 電波が切れても一度開いたページを出すサービスワーカー（本番だけ）
- `docs/` … GitHub Pages。いまは転送のページだけ（`https://yuyami-meguru.github.io/muchu-expo/` → https://encare-dream-expo2026.encourage-school.averix.jp）。QR は `docs/print/qr.svg`（github.io 経由）と `docs/print/qr-site.svg`（新しいアドレスへ直接）

## 手元で動かす
```
npm install
npm run dev          # http://localhost:3470 （合言葉は dev-pass）
npm run check:auth   # 動かしたまま別の窓で。守りの確認
```
お店の人に配る QR は、実行委員でログインして「お店の人に配る QR」から。
開催中・終了後の見え方は、ブラウザにクッキー `dev-phase=during`（または `after`・`before`）を付けて開くと、その端末だけで見られる（手元の next dev だけ。本番では効かない）。

## 「準備中」になっている所（実行委員の画面か、お店の人が自分で埋める）
- 各お店の値段・当日の流れ・「お店の思い」（お店の人が自分のお店の QR から書ける。実行委員は「変更の記録」で確認）
- 茶屋・地域部門の場所、地域部門の企画内容、ラジオ生放送の時刻
- 校内マップのピン（場所の印）を、本物の建物の形に合わせて置き直す（実行委員の「地図のピン」）。トイレ・受付・救護・休憩所のピンも置く。会場の位置は地図のデータの「学校」の建物で、だいたいの位置

## 載せる前に確かめたいこと
入場料・支払い方法、写真撮影のルール、雨の日の扱い（決まったら「ご来場の方へ」と全体の帯の文に）。アレルギーはサイトに載せず「お店の生徒におたずねください」のまま（まちがった情報で困る人が出ないように）。生徒・先生の名前は載せない（未成年の情報のため）。
